# Reinventando Colombia 2030 · Seguimiento ciudadano

App (PWA) de **Vibras Positivas HM** para hacerle seguimiento ciudadano al encuentro Reinventando Colombia 2030 (19–20 oct 2026, Bogotá): 133 proyectos, US$120.324 M, meta de crecer al 6 %, y los compromisos que salen hacia el Plan Nacional de Desarrollo 2026‑2030.

Para actualizar el estado de un compromiso, edita el arreglo `HITOS` en `index.html` (`ok` = cumplido, `run` = en curso, `wait` = pendiente).

No es una app oficial. Resume información pública de medios.
